about=EDEA_EraseTools performs a generic difference/erase operation: it removes the part of a source vector layer (points, lines or polygons) located inside a clip layer, regardless of the geometry type of either layer. Key features: asynchronous processing (QThread, non-blocking UI), simple / batch / preview modes, optional buffer before processing, inverted (clip) mode and symmetric difference, interactive selection of clip features on the map, overlap validation on the clip layer, post-processing topology checks, automatic INSPIRE metadata, multi-format export (Shapefile, GeoPackage, GeoJSON, KML, PostGIS, GeoServer via REST API), matplotlib statistics charts, HTML/CSV reports, exportable action history, and a before/after comparison view. Also available as a QGIS Processing algorithm (Vector overlay > EDEA_EraseTools).

Français : EDEA_EraseTools supprime la partie d'une couche source (points, lignes ou polygones) située à l'intérieur d'une couche de découpe, quel que soit le type de géométrie des deux couches. Fonctionnalités principales : traitement asynchrone, modes simple / par lot / prévisualisation, buffer optionnel, mode inversé (clip) et différence symétrique, sélection interactive des entités de découpe sur la carte, validation des chevauchements, validation topologique post-traitement, métadonnées INSPIRE automatiques, export multi-format (Shapefile, GeoPackage, GeoJSON, KML, PostGIS, GeoServer), statistiques avec graphiques matplotlib, rapports HTML/CSV, historique exportable des traitements, et comparaison visuelle avant/après. Disponible aussi comme algorithme Processing (Vector overlay > EDEA_EraseTools).
